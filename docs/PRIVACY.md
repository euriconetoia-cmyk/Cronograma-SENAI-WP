# Privacidade e retenção

## Dados tratados

O sistema pode armazenar nome e e-mail provenientes do usuário WordPress, vínculo com unidades, condição de validador, estado ativo/inativo, último acesso, autoria de mudanças, comentários, histórico funcional e auditoria administrativa.

## Finalidade

Esses dados são utilizados para autorização, operação do fluxo, rastreabilidade, suporte e segurança.

## Exportação e apagamento

O plugin integra o exportador e o apagador de dados pessoais do WordPress. O apagador remove metadados operacionais que podem ser eliminados sem destruir a rastreabilidade. Histórico e snapshots podem ser retidos conforme política institucional e são informados como itens retidos.

## Retenção sugerida para aprovação institucional

A instituição deve definir formalmente períodos para histórico de turmas, versões, auditoria, backups e logs técnicos. Até essa definição, não realizar limpeza automática de evidências históricas.

## Desinstalação

O plugin preserva dados por padrão ao ser desinstalado. A decisão é intencional para reduzir risco de perda acidental e deve ser considerada no procedimento de encerramento do sistema.
